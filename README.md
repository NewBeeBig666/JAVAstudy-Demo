# JAVAstudy-Demo · Java 学习智能体 Web 原型

面向**本科软件工程专业（Java 方向）**的「学习智能体」交互原型，用于验证三栏式 Agent 工作台的**界面布局**与**学生 / 教师两类角色的操作流程**是否合理。

> 这是一个**交互 Demo**：纯前端、零依赖、零构建，无后端、无数据库、无鉴权，所有数据来自集中管理的 Mock JSON，不做真实评分算法与接口调用。

---

## 特性

- **双视角切换**：顶部一键切换「学生视角 / 教师视角」，在同一 Demo 内连贯演示两类用户流程
- **三栏 Agent 工作台**：最左 Activity Bar + 左侧面板 + 中间对话/任务执行主区 + 右侧可折叠上下文区
- **多智能体编排**：诊断 / 规划 / 辅导 / 代码陪练 / 批改 / 学情 六个 Agent，消息流中带 Agent 标签
- **两条闭环流程**：学生「诊断 → 规划 → 陪练 → 评测 → 掌握度回写」；教师「看板 → 发布 → 批改 → 反馈回流学生侧」
- **完整交互状态**：加载骨架屏与 typing 指示器、空数据、已完成三种状态均可现场触发
- **遵循教学边界**：代码陪练只给三级渐进提示，明确不直接生成完整作业代码

## 快速开始

**方式一：直接打开**

双击 `index.html` 即可运行（无需安装任何东西）。

**方式二：本地静态服务**

```bash
cd learning-agent-demo
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

推荐 Chrome / Edge / Firefox 最新版，窗口宽度 ≥ 1280px 体验最佳。

## 核心流程演示脚本

### 流程一 · 学生：新建学习会话 → 选知识点 → 生成路径 → 完成练习

1. 顶栏切到 **学生视角**，默认进入「学习会话」
2. 左下角 **新建学习会话** → 搜索或选择知识点（如「泛型与反射」）→ 创建
3. 观察两个 Agent 依次产出：
   - **诊断 Agent**：调历史练习与错题本，做依赖链溯源（例：并发 27 分 ← JVM 31 分，根因在内存模型）
   - **规划 Agent**：生成 4 步学习路径（诊断 / 精讲 / 陪练 / 测验）
4. 点击路径任意步骤可展开；用「继续当前步骤」或「直接来一道练习」推进
5. 练习卡片：选答案 → **提交答案** → 立刻出即时评测 → 掌握度回写知识图谱，同时写入练习记录与错题本
6. 四步全部完成后会话自动标记 **已完成** 并产出学习报告
   - 预置会话「集合框架：HashMap 底层原理」就是现成的**已完成**样例
7. 卡片底部 **再要一级提示**：三级渐进提示（思路 → 定位 → 关键结论），提示使用次数教师端可见

### 流程二 · 教师：学情看板 → 发布作业 → 查看提交 → 评分反馈 → 回流学生

1. 顶栏切到 **教师视角**
2. **学情看板**：4 个 KPI、班级卡点知识点 TOP 6、重点关注学生；点「一键生成班级薄弱点报告」可看学情 Agent 的四步任务执行时间线
3. **作业管理** → **发布新作业**（标题 / 关联知识点 / 截止时间 / Rubric 模板）→ 发布；草稿作业可「正式发布给学生」
4. **提交批改** → 点击任一学生行打开抽屉：查看提交代码、AI 初评、相似度检测 → 「采用 AI 初评」或手动调 Rubric 各项 → 填写评语 → **发布评分与反馈**
5. **预警中心**：连续未登录 / 提交次数骤降 / 卡点知识点 / 非正常时段提交 / 代码相似度异常，可标记已处理或推送提醒给学生
6. **切回学生视角 → 我的作业**：新作业与批改反馈都已回流；学生侧会话中也会收到一条批改 Agent 的通知卡片

## 交互状态覆盖

| 状态 | 触发位置 |
| --- | --- |
| **加载中** | 切换任意左侧功能或角色（骨架屏）；Agent 回复前的 typing 指示器；学情 Agent 任务执行时间线 |
| **空数据** | 设置 → 「清空全部学习会话」→ 会话列表与对话区空状态；作业筛选无结果；预警全部处理完 |
| **已完成** | 会话「集合框架」整条路径已完成；已批改作业；已处理预警 |

| 数据 | 规模 |

| 学生提交 | 9 条（待批改 / 已批改 / 未提交），含相似度与提交时段异常 |
| 预警名单 | 6 类，覆盖登录、提交、卡点、时段、相似度异常 |

## 与产品设计文档的对应关系

| 文档要求 | Demo 中的实现 |
| --- | --- |
| 多 Agent 协作编排 | 诊断 / 规划 / 辅导 / 代码陪练 / 批改 / 学情 六类 Agent，消息头带标签 |
| 前端三栏布局 + 快捷指令芯片 | Activity Bar + 左面板 + 主工作区 + 右侧上下文；输入框上方 6 个高频指令 |
| 依赖链溯源 | 知识图谱点击知识点，自动追到最弱前置节点并给出结论 |
| 严禁直接生成完整代码 | 代码陪练卡片只给三级渐进提示，并显式声明边界 |
| Rubric 驱动批改 | 作业带 4 维 Rubric，抽屉内逐项打分 + AI 初评 + 相似度检测 |
| 预警名单 | 学情 Agent 生成 6 类预警，含提交次数骤降、非正常时段、相似度异常 |
| 闭环反馈 | 教师评分 → 学生作业页 + 学生会话通知卡片；练习评测 → 掌握度 + 错题本 + 复习队列 |
| 间隔重复 | 错题自动进入「今日复习队列」，标注 SM-2 复习次数 |
